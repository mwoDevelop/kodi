# ADR-0003: testing canary, następnie globalny stable

Status: zaakceptowany

Zarządzane dodatki są certyfikowane w kanale testing na BlueStacks i X88. Po
sukcesie, review i publikacji stable standardowy updater Kodi może dokonać
globalnej aktualizacji, a QNAP obserwuje konwergencję floty.

Nie opisujemy stable jako fali per urządzenie. Prawdziwie falowa instalacja kodu
wymagałaby wyłączenia auto-update i zarządzanej instalacji dokładnego artefaktu;
nie jest przyjętym modelem MVP.
