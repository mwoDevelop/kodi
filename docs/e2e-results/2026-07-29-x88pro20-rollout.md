Date: 2026-07-29

## Result

The new Android 11 consumer passed:

- verified private backup of the pre-existing Kodi 21.2 profile;
- clean Kodi 21.3 installation and in-process profile restore;
- `repository.mwodevelop` 1.0.0 stable origin verification;
- Umbrella 6.7.81.18, mwoScrapers 0.1.5, mwoScrapers Manager 0.1.1 and
  WatchNixtoons2 0.26.1 stable installation;
- Profile Sync 0.1.6 pairing, authenticated heartbeat, signed candidate check

  failure proving rollback, quarantine, journal cleanup and exact restoration

- WatchNixtoons2 catalogue and controlled playback.

Private reports and the pre-rollout snapshot remain below `.kodi-private` and
are intentionally not committed.

## Compatibility fixes

The box denies the ADB shell access to Kodi's scoped
`Android/data/org.xbmc.kodi` tree while Kodi itself can access it. The rollout
added:

- JSON-RPC readiness fallback when `guisettings.xml` is opaque to ADB;
- in-Kodi origin inspection instead of direct `Addons*.db` access;
- IPv6 loopback support when EventServer listens only on `udp6 :::9777`;
- JSON-RPC repository/add-on checks in the Profile Sync device runner.

These paths preserve the direct ADB checks on devices where they remain
available.

The reversible apply canary is reproducible with:

```bash
PYTHONPATH=. .venv/bin/python \
  tests/e2e/profile_sync_apply_device.py \
  --device x88pro20 \
  --adb /home/mwo/android-sdk/platform-tools/adb \
  --adb-server-port 5037 \
  --result .kodi-private/e2e/x88pro20-profile-sync-apply.json
```

## NordVPN blocker

NordVPN 9.9.2 from Google Play and the official, matching-certificate Android
TV APK both install but reject this device as incompatible. The device exposes
an unlocked/unverified `userdebug` build and no hardware-backed KeyStore or
StrongBox feature. NordVPN documents this exact condition for non-certified
Android TV boxes as a hardware security limitation. No bypass was attempted.

The supported options are a vendor firmware/device with the required
hardware-backed KeyStore or a NordVPN tunnel on the router. Playback with an
active NordVPN tunnel remains pending until one of those supported paths is
available.
