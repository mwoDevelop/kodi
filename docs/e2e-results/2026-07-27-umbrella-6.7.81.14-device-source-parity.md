# Umbrella 6.7.81.14: BlueStacks1 / parzystość źródła Sony

Data: 27.07.2026

## Wynik

Te same trzy odcinki odtwarzane na obu urządzeniach. Każde urządzenie wybierało to samo
źródło Real-Debrid w każdym przypadku, co zweryfikowano za pomocą nieodwracalnego
odcisku palca SHA-256 wybranego skrótu informacji o torrentie.

Podczas testów moduł Sony Kodi pozostawał poprowadzony przez podłączony i zatwierdzony
tunel NordVPN. Rozdzielczość Sony trwała o 9–13 sekund dłużej niż w przypadku
BlueStacks, ale wszystkie strumienie pozostały aktywne przez całe 15-sekundowe okno
obserwacyjne.

## Powielanie

Uruchom z katalogu głównego repozytorium z już podłączonymi urządzeniami ADB:

```bash
ANDROID_ADB_SERVER_PORT=5038 .venv/bin/python \
  tests/e2e/sony_kodi_matrix.py \
  --adb /home/mwo/android-sdk/platform-tools/adb \
  --serial 192.168.1.12:5555 \
  --host 192.168.1.12 \
  --event-via-adb \
  --case breaking_bad_s01e01 \
  --direct-play \
  --timeout 150 \
  --observe-seconds 15 \
  --poll-seconds 0.5 \
  --result /tmp/sony-breaking-bad.json
```

Powtórz polecenie dla `house_of_the_dragon_s01e01` i `house_of_the_dragon_s03e01`.
Obudowy Sony są uruchamiane oddzielnie, ponieważ zatrzymanie odtwarzania Kodi na tym
telewizorze przywraca fokus do aplikacji Sony TV.

W przypadku BlueStacks1 prześlij dalej Kodi JSON-RPC i uruchom wszystkie trzy przypadki:

```bash
/home/mwo/android-sdk/platform-tools/adb -P 5038 \
  -s 127.0.0.1:5555 forward tcp:19190 tcp:9090

ANDROID_ADB_SERVER_PORT=5038 .venv/bin/python \
  tests/e2e/sony_kodi_matrix.py \
  --adb /home/mwo/android-sdk/platform-tools/adb \
  --serial 127.0.0.1:5555 \
  --host 127.0.0.1 \
  --jsonrpc-port 19190 \
  --event-via-adb \
  --case breaking_bad_s01e01 \
  --case house_of_the_dragon_s01e01 \
  --case house_of_the_dragon_s03e01 \
  --direct-play \
  --timeout 150 \
  --observe-seconds 15 \
  --poll-seconds 0.5 \
  --result /tmp/bluestacks-same-episodes.json
```

Moduł uruchamiający nie przechowuje magnesu, rozpoznanego adresu URL ani danych
uwierzytelniających Real-Debrid. Rejestruje tylko pierwszych 16 znaków szesnastkowych
`SHA-256(info_hash)`.
