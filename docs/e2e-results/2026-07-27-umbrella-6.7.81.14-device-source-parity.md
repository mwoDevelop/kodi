# Umbrella 6.7.81.14: BlueStacks1 / Sony source parity

Date: 2026-07-27

## Outcome

The same three episodes played on both devices. Each device selected the same
Real-Debrid source for each case, as verified by a non-reversible SHA-256
fingerprint of the selected torrent info hash.

Sony Kodi remained routed through the connected and validated NordVPN tunnel
during the tests. Sony resolution took 9-13 seconds longer than BlueStacks, but
all streams remained active for the complete 15-second observation window.

## Reproduction

Run from the repository root with ADB devices already connected:

```bash
ANDROID_ADB_SERVER_PORT=5038 .venv/bin/python \
  tests/e2e/sony_kodi_matrix.py \
  --adb /home/mwo/android-sdk/platform-tools/adb \
  --serial 192.168.1.12:5555 \
  --host 192.168.1.12 \
  --event-via-adb \
  --case breaking_bad_s01e01 \
  --direct-play \
  --timeout 150 \
  --observe-seconds 15 \
  --poll-seconds 0.5 \
  --result /tmp/sony-breaking-bad.json
```

Repeat the command for `house_of_the_dragon_s01e01` and
`house_of_the_dragon_s03e01`. Sony cases are run separately because stopping
Kodi playback on this TV returns focus to the Sony TV application.

For BlueStacks1, forward Kodi JSON-RPC and run all three cases:

```bash
/home/mwo/android-sdk/platform-tools/adb -P 5038 \
  -s 127.0.0.1:5555 forward tcp:19190 tcp:9090

ANDROID_ADB_SERVER_PORT=5038 .venv/bin/python \
  tests/e2e/sony_kodi_matrix.py \
  --adb /home/mwo/android-sdk/platform-tools/adb \
  --serial 127.0.0.1:5555 \
  --host 127.0.0.1 \
  --jsonrpc-port 19190 \
  --event-via-adb \
  --case breaking_bad_s01e01 \
  --case house_of_the_dragon_s01e01 \
  --case house_of_the_dragon_s03e01 \
  --direct-play \
  --timeout 150 \
  --observe-seconds 15 \
  --poll-seconds 0.5 \
  --result /tmp/bluestacks-same-episodes.json
```

The runner does not persist a magnet, resolved URL, or Real-Debrid credential.
It records only the first 16 hexadecimal characters of
`SHA-256(info_hash)`.

Machine-readable results:
`2026-07-27-umbrella-6.7.81.14-device-source-parity.json`.
