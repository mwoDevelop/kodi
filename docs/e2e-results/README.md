przydatne do analizy regresji, ale nie reprezentują bieżącej dostępności urządzenia ani
kondycji usług. Użyj [poleceń weryfikacji zaplanowanego
procesu](../scheduled-processes.md#operational-verification) i bieżących testów urządzeń
